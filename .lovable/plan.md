# Privacidade inicial do painel

## Alterações
- Manter os dados protegidos pela tela de login existente.
- Iniciar cada acesso com todos os valores financeiros ocultos.
- Adicionar um botão no topo para mostrar ou ocultar os valores quando desejar.
- Não listar clientes ao abrir o painel; liberar a lista somente após escolher um filtro ou fazer uma busca.
- Aplicar a ocultação também aos indicadores, gráficos e totais da tabela.

## Verificação
- Confirmar que o painel abre sem nomes de clientes e sem valores.
- Confirmar que um filtro libera os clientes, mantendo valores ocultos.
- Confirmar que o botão revela e oculta os valores sem alterar os dados.
